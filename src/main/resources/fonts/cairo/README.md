# Cairo (receipt PDFs)

Static Regular (wght 400) and Bold (wght 700) instances of the Cairo variable font
(https://github.com/Gue3bara/Cairo, `fonts/Cairo/variable/Cairo[slnt,wght].ttf`), made with
`fonttools varLib.instancer <font> wght=400|700 slnt=0`. PDFBox embeds static fonts reliably;
variable fonts it does not. Licensed under the SIL Open Font License 1.1 — see `OFL.txt`.
