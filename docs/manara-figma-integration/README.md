# Manara Figma integration

Canonical record for the Settings / public-courses / billing programme driven by the
`manara-phase-prompts` pack (phases 00–11). The frontend repository links here; it keeps no copy.

- `execution-board.md`, `orchestration-state.json` — task status and resume point
- `implementation-plan.md` — repositories, commands, worktrees, migrations, task list
- `api-contracts.md` — agreed and proposed API contracts
- `gap-coverage.md` — every report ID with owner phase and evidence
- `design-source-map.md` — Figma export files → target code
- `decisions-and-blockers.md` — decisions and external prerequisites
- `phase-NN-handoff.md`, `phase-11-*-validation.md` — per-phase evidence
